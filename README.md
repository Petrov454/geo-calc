# C++ Min-Heap Template Generator

**Автор:** Петров Константин Сергеевич, Группа М3119

## Описание
Данный проект представляет собой расширение (плагин) для среды разработки Visual Studio Code. Плагин предназначен для быстрой генерации низкоуровневого каркаса структуры данных «Бинарная куча» (Min-Heap) на языке C++. Код шаблона оптимизирован для стандартов вплоть до C++26 и использует ручное управление памятью (сырые динамические массивы, указатели и адресную арифметику) без привлечения контейнеров стандартной библиотеки. 

Расширение разработано для упрощения выполнения лабораторных работ по курсу алгоритмов и структур данных.

## Возможности (Features)
* **Быстрая вставка шаблона:** Мгновенная генерация C++ класса `MinHeap` со встроенными методами `push` и `heapify_up`.
* **Горячие клавиши:** Вызов генерации по сочетанию клавиш `Ctrl + Shift + H` (или `Cmd + Shift + H` на macOS) при фокусе на текстовом редакторе.
* **Вызов через палитру команд:** Плагин доступен в Command Palette (`Ctrl + Shift + P`) по запросу `Generate C++ Min-Heap Template`.
* **Поддержка типизации:** Сгенерированный код использует `template <typename T>`, что позволяет работать с любыми типами данных.

## Архитектура
Плагин использует `vscode.window.activeTextEditor` для определения текущего активного файла и позиции курсора, после чего применяет метод `editBuilder.insert` для безопасной модификации текстового буфера.
