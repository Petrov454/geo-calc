# Geo Calc

**Автор:** Петров Константин Сергеевич, группа М3119

## Описание
Geo Calc — плагин для VS Code, который считает прямо в редакторе: площадь и периметр фигур, а также арифметические выражения. Вы пишете условие, а плагин сам показывает правильный ответ справа от строки.

## Возможности
* **Автоматическая подсказка с ответом:** `площадь прямоугольника 10 5` → 50
* **Функции в коде:** `area(10, 5)`, `perimeter(3, 4, 5)`, `circle_area(3)`
* **Фигуры:** прямоугольник, квадрат, круг, треугольник (по трём сторонам)
* **Выражения с маркером `=?`:** `2*(10+5) =?` → 30
* **Вписывание результата в код:** `Ctrl+Alt+E` (`Cmd+Alt+E` на macOS)
* **Включение и выключение подсказок:** команда «Geo Calc: Вкл/выкл подсказки» в палитре команд (`Ctrl+Shift+P`)

## Архитектура
Логика вычислений вынесена в `src/calc.ts` и не зависит от VS Code. Файл `src/extension.ts` подключает её к редактору: регистрирует команды и показывает подсказки через декорации (`setDecorations`).

## Запуск
1. `npm install`
2. `npm run compile`
3. Открыть папку в VS Code и нажать F5
